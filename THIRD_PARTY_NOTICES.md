# Avisos de terceiros / Third-party notices

**Código de terceiros / Third-party code:** nenhum. O projeto não tem dependências externas: usa apenas os frameworks do macOS (AppKit, SwiftUI, ScreenCaptureKit, CoreGraphics, CoreImage, ImageIO, Carbon, Combine e Foundation). / None. The project has no external dependencies; it only uses macOS system frameworks.

**Ícones / Icons:** a interface usa **SF Symbols** (Apple). A Apple só permite o seu uso em apps para plataformas Apple, e não em logótipos nem ícones da app. Numa versão para outra plataforma terão de ser substituídos por ícones próprios. / The UI uses Apple's **SF Symbols**, licensed for use in apps on Apple platforms only, not for logos or app icons. A port to another platform needs its own icons.

**Tipos de letra / Fonts:** as fontes oferecidas para o texto das anotações (por exemplo Helvetica Neue, Georgia, Menlo) são só **referidas pelo nome** e vêm do sistema do utilizador; não são distribuídas com a aplicação. / The fonts offered for annotation text are only referenced by name and come from the user's system; they are not bundled.
