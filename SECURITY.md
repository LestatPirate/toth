# Segurança / Security

**PT:** Se encontrou uma vulnerabilidade no Toth, use **Security → Report a vulnerability** (relatório privado) neste repositório do GitHub, com a descrição e os passos para a reproduzir. Pedimos que não a divulgue publicamente antes de haver correção. A aplicação é local, só faz um pedido à internet (a verificação de atualizações, que pode ser desligada) e não tem contas, o que reduz a superfície de ataque.

**EN:** If you found a vulnerability in Toth, please use **Security → Report a vulnerability** (private report) in this GitHub repository, with a description and steps to reproduce. Please don't disclose it publicly before a fix is available. The app is local, makes a single internet request (the update check, which can be turned off) and has no accounts, which keeps the attack surface small.

Versões suportadas / Supported versions: a mais recente / the latest release.
